# Cybersecurity Awareness & Training

This section contains portfolio artefacts for human-risk reduction and employee security awareness.

## Included Artefacts
- Cybersecurity awareness programme
- Phishing/social-engineering scenario pack
- Employee training deck
- Awareness materials pack
- Knowledge and behaviour assessment pack
- Synthetic awareness metrics dashboard
- Management reporting pack

The material demonstrates how awareness programmes can move beyond generic training by combining realistic scenarios, practical employee guidance, measurable learning outcomes, reporting readiness and management communication.

> Any example metrics shown are synthetic demonstration data and are not presented as real employee results.
