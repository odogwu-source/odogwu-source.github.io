FEATURED CASE

Alert 1000 — Suspicious External Email / Inheritance Phishing

22 August 2026 • True Positive • No Escalation

An unsolicited inheritance-themed email requested banking information. SIEM pivots using the subject, sender and recipient validated and scoped the activity. The phishing attempt was confirmed, but the available evidence did not establish user interaction, endpoint compromise or account compromise, supporting remediation without escalation.

  • 7 investigation screenshots
  • Sender, recipient and subject SIEM pivots
  • 5Ws incident documentation
  • True Positive classification with proportional escalation reasoning
  • Remediation focused on removal, blocking, monitoring and user-risk reduction

ANALYST WORKFLOW

How the investigations are performed

Evidence drives both the verdict and the response decision.

1. Review alert context, severity and affected entity.

2. Examine sender, recipient, subject, URLs, attachments and authentication indicators.

3. Pivot through SIEM using sender, subject, recipient, URL, IP and domain indicators.

4. Correlate email events with endpoint, firewall and network telemetry where available.

5. Document findings using the 5Ws framework.

6. Classify the alert and determine whether escalation is proportionate to the observed impact.

7. Recommend containment, remediation and follow-up monitoring.
