GRC PORTFOLIO • LAB PREPARATION

ISO/IEC 27001 Policy & Control Mapping

A GRC case study prepared to demonstrate how security requirements can be translated into policy expectations, control ownership, implementation evidence and remediation tracking.

Objective

Review a simulated security environment, identify relevant control requirements and document whether appropriate governance and security practices are evidenced.

Planned Deliverables

  • Control mapping matrix
  • Policy requirements
  • Control ownership
  • Evidence requirements
  • Gap observations
  • Remediation tracker

Hands-on Evidence

Pending. Lab screenshots and observations will be incorporated when the practical work is performed.

Method

Define scope → identify information-security requirements → review available evidence → map applicable controls → record gaps → assign owners → recommend remediation → track status.

Professional Focus

This project is designed to show the bridge between technical cybersecurity knowledge and governance: not merely identifying a weakness, but determining the control, ownership, evidence and remediation needed to manage it.

Status

Case-study structure complete; evidence collection pending hands-on training.
