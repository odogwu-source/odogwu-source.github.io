Threat Hunting Ransomware Investigation

Credential dumping, remote PowerShell execution, malicious payload transfer and mass file encryption across WKSTN-02 and WKSTN-03.

Case outcome: Evidence supported a coordinated ransomware intrusion sequence involving Invoke-SharpKatz, PowerShell Invoke-Command, retrieval of 777bomb.exe from 7zipp.org, execution as bomb.exe, and file encryption with the .777zzz extension.

Training disclosure: This case was completed in a controlled TryHackMe threat-hunting simulation and is presented to demonstrate investigation methodology, evidence correlation and incident-response judgement.

Reconstructed Attack Chain

1. Credential Access — Invoke-SharpKatz activity observed on WKSTN-02.
2. Execution — PowerShell Invoke-Command used to continue attacker activity.
3. Lateral Movement — Remote execution targeted WKSTN-03.
4. Tool Transfer — 777bomb.exe retrieved from 7zipp.org and written as bomb.exe.
5. Payload Execution — bomb.exe process creation confirmed on WKSTN-03.
6. Impact — High-volume encryption activity produced .777zzz file extensions.

Key Findings

Credential Dumping

PowerShell Script Block telemetry exposed Invoke-SharpKatz on WKSTN-02, supporting credential-access activity.

Remote Execution

PowerShell remoting linked WKSTN-02 to WKSTN-03, establishing the lateral-movement path.

Payload Delivery

Telemetry showed retrieval of http://www.7zipp.org/a/777bomb.exe and execution as bomb.exe.

Ransomware Impact

Event 4103 telemetry showed repeated Encrypting: operations and the .777zzz suffix on affected files.

Recommended Response

Contain

Isolate both affected workstations and revoke compromised credentials.

Block

Block 7zipp.org, 206.189.34.218 and related payload indicators.

Eradicate

Remove malicious artifacts, investigate persistence and rebuild hosts if integrity is uncertain.

Recover & Hunt

Validate backups, restore clean systems and hunt enterprise-wide for related activity.

Analyst Assessment

The value of this investigation lies in correlating separate telemetry into one defensible incident narrative. Credential-access evidence, remote PowerShell, external payload retrieval, remote process creation and mass encryption were connected by host, user, timestamp and attacker objective rather than handled as isolated events.
