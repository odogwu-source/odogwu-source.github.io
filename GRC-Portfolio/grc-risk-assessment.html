GRC PORTFOLIO • COMPLETED HANDS-ON SIMULATION

TechStart Inc. — ISO 27001 Cloud Migration Risk Assessment

A hands-on GRC simulation in which I acted as the GRC analyst for a B2B SaaS organisation migrating a customer database containing more than five million records from on-premises infrastructure to AWS while preparing for ISO/IEC 27001:2022 certification.

Scope

Cloud migration risk assessment, critical-asset identification, risk-register development, ISO 27001 Annex A control selection, control-effectiveness assessment and risk-treatment planning.

Completed Work

  • Catalogued 3 critical production assets
  • Assessed and documented 5 security risks
  • Implemented and assessed 5 ISO 27001 controls
  • Created 5 risk treatment plans with owners and deadlines

Outcome

Completed all 4 project tasks and produced a coherent risk-to-control-to-treatment workflow suitable for management and audit review.

Critical Assets

Customer Database — production repository containing 5M+ customer records; AWS Cloud Infrastructure — production cloud environment supporting the migration; SaaS Platform Application — customer-facing production application dependent on the AWS environment and customer data.

Risk Register Highlights

Unauthorized Database Access

External attacker exploits weak access controls, causing unauthorized access to the customer database. Likelihood 4 × Impact 5 = Critical.

Cloud Misconfiguration

AWS configuration errors expose customer data during migration. Likelihood 4 × Impact 5 = Critical.

Service Disruption

Migration failure or configuration error causes customer database unavailability and operational disruption. Likelihood 3 × Impact 5 = High.

Cloud Storage Exposure

Misconfigured cloud storage exposes sensitive customer information and creates breach, regulatory and reputational risk.

Unpatched Cloud Systems

Attackers exploit technical vulnerabilities in cloud-hosted systems, causing compromise and service disruption.

ISO/IEC 27001:2022 Controls Applied

  • A.5.17 Authentication information: MFA for privileged and administrative access.
  • A.8.24 Use of cryptography: encryption of sensitive customer data at rest and in transit.
  • A.8.13 Information backup: automated backups and tested recovery.
  • A.8.8 Management of technical vulnerabilities: vulnerability scanning and timely remediation.
  • A.8.15 Logging: centralized logging and continuous security-event monitoring.

Risk Treatment

Each identified risk was assigned a mitigation strategy, accountable owner, target date and action plan. Treatments included least-privilege IAM, MFA, secure AWS configuration baselines, encryption, configuration monitoring, backup and failover planning, storage-access restrictions, vulnerability scanning and patch management.

Skills Demonstrated

Asset classification • risk identification • likelihood/impact scoring • risk-register documentation • ISO 27001 Annex A mapping • control design • control-effectiveness assessment • risk ownership • remediation planning • cloud security governance.

Portfolio Integrity

This is a hands-on training simulation, not a real client engagement or certification audit. The case study documents the GRC decisions and artifacts produced during the exercise.
